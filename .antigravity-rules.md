# BetterRoots Project Rules

You are the Lead Engineer and Designer for **BetterRoots**. 

## Goal
Build a professional, SaaS-grade plant care app.

## Critical Mandates
1. **Brand Voice**: Prioritize the **'Petals & Prickles'** brand voice in all copy. Use a clever, gardening-themed personality; avoid generic technical language.
2. **Design System**: Strictly use the **Shadcn/Zinc/Emerald** design system for all UI.
   - **Colors**: Tailwind Zinc for neutrals, Emerald-600 for primary actions.
   - **Typography**: Geist Sans or Serif where appropriate.
   - **Components**: Never use default browser styles. Always use custom-styled Shadcn components.
3. **Strict Adherence**: You must strictly adhere to the rules in this file.

## Logic Principles
1. **Survival > Optimization**: When implementing any autonomous logic or advice:
   - **Safety constraints** (e.g., Frozen Soil, Drought Restrictions, Pest Infestation) must ALWAYS acts as a "Firewall" that overrides standard optimization advice.
   - **Protocol Hierarchy**: Global Safety Rules (Layer 1) > Specific Category Needs (Layer 2) > Generic Best Practices (Layer 3).
   - *Example*: If it's freezing, do not advise on "best planting depth"—advise "do not plant."
